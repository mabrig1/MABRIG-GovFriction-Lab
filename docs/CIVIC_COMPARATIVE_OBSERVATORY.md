# Civic comparative observatory and upstream attribution
Source reviewed: https://github.com/nishchalaaa/Civic-Operations-Analytics at commit ff51e8be005b2f0837964ce655714efeae3d4f57. MIT, copyright Nishchala Reddy Satish Kumar. Two exact reference SQL files and upstream LICENSE are retained in third_party/civic-operations-analytics. This is selective vendoring, not a full clone. Upstream synthetic data, database, figures, hard-coded percentages and SLA assumptions are deliberately excluded. The adapted browser implementation compares audited within-service groups rather than claiming equivalent SLA metrics. No upstream SQL is executed in production.
New comparative module reports nonclosure, restricted delay, friction, absolute/signed disparity, composite score, average-tie ranks and descriptive Spearman associations. It uses identical scoreable boroughs for every indicator within a service. Rank changes show different ordering, not superior measurement. With five boroughs correlations are descriptive and unstable; null for fewer than three or constant ranks. No causal or external validity claims. Figure is a standalone SVG with accessible text, fixed 0–100 scale and synthetic/provenance marker. JSON is authoritative for exact signed numbers; existing CSV escapes formula-like fields. Existing CPU monthly trend already handles the temporal view; this PR does not introduce a second inconsistent trend engine.
Research paper: use as a conventional-indicator comparator for incremental information evaluation; report rank concordance and cases of reversals; do not interpret directionless asymmetry as disadvantage without signed gap. The upstream project is not a peer-reviewed competitor or evidence of scientific novelty. More extensive comparisons and external validation remain required.
