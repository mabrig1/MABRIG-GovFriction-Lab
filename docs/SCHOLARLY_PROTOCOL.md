## Proposed standalone article protocol
Title: Measuring Bureaucratic Processing Friction and Geographic Asymmetry in Urban Public Service Administration: Computational Evidence from NYC 311.
Primary question: How do recorded nonclosure, restricted delay and within-service differences vary across five boroughs for DSNY Graffiti and Missed Collection (All Materials), January–March 2025?
Cohort: all eligible requests created 2025-01-01 inclusive to 2025-04-01 exclusive. Freeze exact downloaded bytes, manifest, extraction date, query and documented observation cutoff. Do not label a later download as an earlier as-of snapshot. Confirm categories and cutoff against provenance; do not substitute synthetic or truncated data. The existing default snapshot is 2026-11-19; confirm applicability to source before reporting.
Primary analysis: 30-day horizon, minN=10, friction weight .70, absolute within-service pooled other-borough comparator. Report signed F-peer difference alongside index to avoid confusing favorable and unfavorable disparities. Wilson intervals only for nonclosure; no composite intervals. Sensitivity: 15/30/45/60/90 days and weights 0/.25/.5/.7/.75/1; report changed eligible counts and within-service ranks, not p-values. Report uncertainty limits and compare single components rather than assert composite superiority.
Data source: NYC Open Data erm2-nwe9. Run reference/fetch_nyc311.py without --max-records; verify manifest and compare browser output against the independent Kaggle reference. A live API is mutable and pagination can drift, so preserve the actual frozen bytes and verify coverage. No empirical results are included here.
Primary outputs: audit flow, group counts, nonclosure with Wilson intervals, restricted delay, signed and absolute peer differences, composite score, sensitivity table. Existing browser CSV exports protect formula-like cells; use JSON for exact numeric values including negative signed differences. No DOI is asserted. Methods record logs engine version, not an immutable software commit; archive exact release commit before publication.
Limitations: reported requests only; closure not physical resolution; observational noncausal differences; no adjusted inference or composite confidence intervals; fixed NYC scope; no independent validation of new sensitivity output yet. Disclose prior analysis, software authorship and AI assistance as required. Do not publish row identifiers or addresses. Review source terms and ethics requirements.
