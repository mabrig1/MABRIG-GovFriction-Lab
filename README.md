# MABRIG GovFriction Lab

Research prototype for the Bureaucratic Friction & Service-Delivery Asymmetry Index (BFS-DAI).

The first web implementation is being added in a review branch. The intended application processes administrative CSV records locally in the browser, audits data quality, calculates descriptive friction and peer-asymmetry measures, and exports reproducible comparison outputs. The included demonstration uses synthetic records and must not be described as genuine NYC findings.

See the implementation pull request for the web code and Cloudflare deployment configuration.
